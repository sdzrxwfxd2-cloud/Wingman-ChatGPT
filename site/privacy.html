Privacy notice

This is a short, plain note about the information this website records when you visit. It is not legal advice, and it does not try to cover every law in every country. South Africa’s Protection of Personal Information Act (POPIA) is the law we have in mind, because that is where the site is run from.

What we collect

When a page loads, the site sends a small first-party note to our own servers (not to an advertising network). That note can include:

  • the time of the visit
  • the page you opened, and the page that referred you here if the browser sends one
  • your IP address
  • country, region and city, as Cloudflare reports them from that IP
  • browser, operating system, device type and, where the browser shares it, the device model (for example “iPhone”)
  • screen size, language, time zone and a rough network type
  • a random session number kept only in this browser tab, so we can see which pages were opened in the same visit

Your name is not collected. Phones and computers do not share the owner’s name with a website, and we do not ask for it in this note.

If you tap “Near me” or “Nearest”, your precise location stays on your device so the list can be sorted by distance. That location is not sent to our servers.

Why we collect it

So the people who run the site can see that it is working, what is being used, and roughly who is visiting — for running and improving the service, and for basic security (for example spotting unusual traffic).

How long we keep it

Visit records are kept for 90 days, then removed.

Who can see it

The detailed visitor log sits on a private page that needs an admin password. It is not shown to other visitors.

Contact

If you have a question about this notice, or you would like a record removed sooner than 90 days, contact the people who run Go Around through any public channel they publish for the site. This page does not list a personal name.
