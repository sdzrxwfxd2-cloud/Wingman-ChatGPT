# Notes for the aerodrome page

Short lines the aerodrome page can show with a verdict. Guidance only. Do not name the licence holder’s occupation. Do not show personal names.

## Always on

- Guidance only — the person in command decides.

## When the weather comes from a model

- Model estimate only — not an official weather report.

Use this for GO, CAUTION and NO-GO alike. It is a disclaimer, not a reason to hide a GO.

## When the official report is ageing

- Weather report is getting stale (N min old).

Show this when the METAR or SPECI is more than 60 minutes old and still being used (up to 90 minutes).

## When there is no current report

- No current weather report, forecast or model.
- METAR NIL (no report).
- No current METAR — using the TAF that covers now.
- TAF for ETA ±1 h.
- TAF covering ETD.
- Model data is older than 90 min.
- Model data is older than 180 min and was not used.

## Cloud and visibility

- Cloud height not reported (BKN/OVC/VV///) — treat as below minima.
- Visibility not in METAR, model shows X km.
- Visibility not in METAR, no model value.
- Ceiling X ft below 1500 ft (CTR/ATZ VFR minimum).
- Ceiling X ft below 1500 ft — uncontrolled field, stay clear of cloud.
- Ceiling X ft — below 1000 ft, no VFR circuit clear of cloud.
- Visibility X km below VFR 5 km.

## Model close to a limit

- Model value is close to the limit, treated as caution.
- Model value is clearly beyond the applicable limit.

## Night

- Night not selected (after sunset).
- Night in N min, night not selected.

Do not claim that night flying facilities have been checked.

## Heliport

- Heliport — no go / caution / no-go verdict.

## Forecast labels

Every reason that comes from a TAF starts with “TAF forecast:” so it cannot be confused with a current report.

A TREND reason starts with “METAR trend TEMPO” or “METAR trend BECMG”. NOSIG may be shown as: METAR NOSIG — no significant change expected for 2 h (TREND supersedes the TAF).

## Words the page must not use

- Do not say cleared, authorised, legal or illegal.
- Do not use Special VFR as if it were a go. If it is ever mentioned, say only that a clearance might be possible in a control zone by day, and that it is never a substitute for air traffic control.
- INCOMPLETE means “there is not enough current weather”, not “do not go”.
